# Orquestrador

Sistema de agentes do José para criar histórias e vídeos com IA, operado pelo Claude Code. Abra a sessão nesta pasta.

| Área | O que tem |
|---|---|
| CLAUDE.md | regras do orquestrador, a lógica roteirista → diretor → atuação e os 7 pilares |
| .claude/ | os 7 agentes (pilares), as skills e os cadernos dos agentes |
| Box_de_Ideias/ | ideias soltas, referências (criativos e ads) e os DNAs dos vídeos analisados |
| Diretrizes/ | diretrizes do José: tom, marca, canais, clientes |
| _Sistema/ | pipeline, checklist, padrões, ferramentas, templates, academia (catálogo de skills e material dos métodos) e lições |
| Projetos/ | um projeto por pasta, cada um com o seu status.md |
| Biblioteca/ | o que deu certo e pode voltar: roteiros, personagens, cenários, prompts e músicas |
| _instalacao/ | o kit: como usar, o painel ao lado da conversa e a rede no segundo monitor |
