# Modelos (não ativos)

Agentes e documentos do kit original, com os nomes trocados para o Orquestrador. Ficam aqui como base para definir os pilares 2 a 7. Nada nesta pasta é carregado pelo Claude Code.

| Arquivo | O que é no kit original |
|---|---|
| agentes/form.md | direção de campanha, marca, direitos, referências, materiais do cliente |
| agentes/stock.md | biblioteca, inventário e geração de assets base |
| agentes/code.md | fichas e prompts de geração, pipeline, corte técnico e timeline XML |
| agentes/visual.md | revisão de qualidade, estética, cor e impacto |
| agentes/delivery.md | pacote final, nomes, conferência e mensagem de entrega |
| agentes/skill.md | Academia: cursos, treino, cadernos e retrospectiva |
| academia/ | catálogo e histórico da Academia, usados pelo agente skill |
| pipeline-video-ia.md | a cadeia completa de um vídeo comercial por IA, da ideia à entrega |

Para adotar um modelo, siga "Ao definir um novo pilar" no `LEIA-ME.md`.
